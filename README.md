# ЛР №2 — Калькулятор для Android (Java)

Калькулятор вычисляет сложные выражения с учётом приоритета операций, например
`12−(sin(3^3)+ln(√4))` = `10.350476891`.

**Что умеет**

- `+ − × ÷`, скобки, степень `xʸ`, квадрат `x²`, корень `√`, факториал `n!`, процент `%` (`200×15%` = 30);
- функции `sin cos tan cot ln log` и константы `π`, `e`; кнопка `RAD/DEG` переключает радианы и градусы;
- неявное умножение: `2π`, `3(1+2)`, `2√9`;
- предпросмотр результата прямо во время ввода; при нажатии `=` недостающие `)` дописываются сами;
- отдельные разметки для портретной (`res/layout`) и альбомной (`res/layout-land`) ориентации;
- выражение, результат и режим RAD/DEG сохраняются при повороте экрана (`onSaveInstanceState` / `onRestoreInstanceState`);
- понятные сообщения об ошибках: деление на ноль, корень из отрицательного числа, логарифм от числа ≤ 0,
  факториал дробного числа, tan(90°), лишняя или незакрытая скобка, переполнение и т. д.

**Основные файлы**

| Файл | Что в нём |
|---|---|
| `app/src/main/java/com/example/calculator/MainActivity.java` | Экран: обработка нажатий, сохранение состояния, логирование жизненного цикла |
| `app/src/main/java/com/example/calculator/ExpressionEvaluator.java` | Разбор и вычисление выражения (рекурсивный спуск) |
| `app/src/main/res/layout/activity_main.xml` | Разметка для портретной ориентации |
| `app/src/main/res/layout-land/activity_main.xml` | Разметка для альбомной ориентации |
| `app/src/main/res/values/` | Строки, цвета, стили кнопок (`values-night` — тёмная тема) |
| `app/src/test/.../ExpressionEvaluatorTest.java` | Unit-тесты вычислителя |
| `docs/answers.md` | Ответы на контрольные вопросы |

## Шаг 1. Установка Android Studio на Mac

1. Узнайте, какой у вас процессор: меню  → **Об этом Mac**. Если там написано **«Чип Apple M1/M2/M3/M4…»**, у вас Apple Silicon; если **«Процессор Intel»**, то Intel.
2. Откройте <https://developer.android.com/studio>, нажмите **Download Android Studio**, примите соглашение и выберите
   **Mac with Apple chip** или **Mac with Intel chip** (как в п. 1). Скачается файл `.dmg` (~1–1,5 ГБ).
   *Если у вас стоит Homebrew, можно вместо этого выполнить в Терминале `brew install --cask android-studio`.*
3. Откройте `.dmg` и перетащите **Android Studio** в папку **Программы (Applications)**.
4. Запустите Android Studio из Программ или Launchpad. Если macOS спросит, открывать ли программу, загруженную из интернета, нажмите **Открыть**.
5. На вопрос об импорте настроек выберите **Do not import settings**.
6. В мастере настройки (Setup Wizard): **Next** → тип установки **Standard** → **Next** → выберите тему → **Next**.
7. На экране **License Agreement** нажмите **по очереди на каждую лицензию в списке слева** и для каждой выберите **Accept**. Затем **Finish**.
8. Подождите, пока скачаются Android SDK и эмулятор: это несколько гигабайт, обычно 10–30 минут. Нужно ~15–20 ГБ свободного места на диске.

## Шаг 2. Скачать проект

Проще всего через браузер:

1. Откройте <https://github.com/AliakseiPytsel/aliplexxx_code>.
2. Слева вверху переключите ветку на **`claude/android-studio-mac-setup-ueonjq`** (или на `main`, если ветка уже влита).
3. **Code** → **Download ZIP**, затем распакуйте архив (двойной клик в Finder).

Или через Терминал:

```bash
git clone -b claude/android-studio-mac-setup-ueonjq https://github.com/AliakseiPytsel/aliplexxx_code.git
```

## Шаг 3. Открыть проект в Android Studio

1. На стартовом экране нажмите **Open** (или **File → Open…**) и выберите **папку проекта**, ту, в которой лежит `settings.gradle.kts`.
2. На вопрос *Trust and open project?* ответьте **Trust Project**.
3. Подождите, пока закончится **Gradle Sync** (полоса прогресса внизу справа). Первый раз это 3–10 минут: скачиваются Gradle и библиотеки.
4. Если Studio предлагает **Install missing platform(s) and sync project**, нажмите эту ссылку.
   Если предлагает обновить Android Gradle Plugin (**Upgrade**), это можно пропустить: проект работает и без обновления.

## Шаг 4. Создать эмулятор и запустить

1. Откройте **Tools → Device Manager** (или значок телефона на правой панели).
2. **+** → **Create Virtual Device** → категория **Phone** → например **Pixel 8** → **Next**.
3. Выберите рекомендованный образ системы (верхний в списке), нажмите значок загрузки ⬇ рядом с ним, дождитесь загрузки → **Next** → **Finish**.
4. В верхней панели Studio выберите созданное устройство и нажмите зелёную кнопку **▶ Run 'app'** (⌃R).
5. Эмулятор запустится, и на нём откроется калькулятор.

**Поворот экрана:** на панели рядом с эмулятором есть кнопки поворота ⟲ ⟳.
Если интерфейс не поворачивается, проведите в эмуляторе пальцем (мышью) сверху вниз и включите **Автоповорот / Auto-rotate**.

**Вместо эмулятора можно использовать свой Android-телефон:** Настройки → О телефоне → 7 раз нажмите на «Номер сборки», после этого
в разделе «Для разработчиков» включите **Отладку по USB**, подключите телефон кабелем и разрешите отладку на телефоне.
Телефон появится в списке устройств в Studio.

## Шаг 5. Что показать преподавателю

| Проверка | Ожидаемый результат |
|---|---|
| `12−(sin(3^3)+ln(√4))` → `=` | `= 10.350476891` |
| `2+3×4` → `=` | `= 14` (приоритет операций) |
| `5!`, `√` `9`, `log(100)`, `2^10` | `120`, `3`, `2`, `1024` |
| `DEG` → `sin(30)` → `=` | `= 0.5` |
| `5÷0` → `=` | красным: «Деление на ноль» |
| `√(−4)`, `ln(0)`, `2.5!`, `DEG` + `tan(90)` | понятное сообщение об ошибке |
| Ввести выражение и повернуть экран | открылась альбомная разметка, выражение и результат остались на месте |

Жизненный цикл можно показать в окне **Logcat** (внизу Studio): введите в фильтр `tag:MainActivity` и поверните экран.
Появится цепочка `onPause → onStop → onSaveInstanceState → onDestroy → onCreate → onStart → onRestoreInstanceState → onResume`.

Unit-тесты: откройте `ExpressionEvaluatorTest.java`, нажмите правой кнопкой мыши → **Run 'ExpressionEvaluatorTest'**.

## Если что-то пошло не так

- **Ошибка Gradle про JDK / «Unsupported class file major version»**: **Android Studio → Settings** (⌘,) → **Build, Execution, Deployment → Build Tools → Gradle** → **Gradle JDK**: выберите встроенный **jbr-21** (или **Download JDK…** → версия 21) → **OK** → **File → Sync Project with Gradle Files**.
- **«SDK location not found»**: откройте проект именно через Android Studio. Она сама создаст `local.properties` с путём к SDK.
- **Sync завис или упал из-за сети**: **File → Sync Project with Gradle Files** ещё раз; при необходимости отключите VPN.
- **Эмулятор не запускается на Mac с Intel**: в Device Manager выберите образ системы `x86_64`. Если не помогает, используйте реальный телефон.
